🎵 What is Harmonic Drive?

Harmonic Drive combines traditional lane-based rhythm gameplay with highly reactive visual effects and extensive player customization.

Instead of treating the background as a passive visualizer, Harmonic Drive’s Emotional Motion System (EMS) allows charts and creators to control the visual presentation of a song alongside its notes.

The game supports both built-in content and community-created charts through the Steam Workshop.

Whether you want to chase leaderboard scores, create charts, experiment with EMS effects, play with friends, or contribute code, Harmonic Drive is designed to be expanded.

✨ Features

Rhythm Gameplay

* 4-key through 8-key chart support
* Multiple difficulty levels
* Multiple gameplay modes
* Customizable note speeds and gameplay settings
* Input calibration for low-latency play
* Score and combo systems
* Online leaderboards
* Steam achievements
* Gameplay modifiers and unlockable loadouts

Emotional Motion System (EMS)

Harmonic Drive includes its own visual effects system called the Emotional Motion System.

EMS allows songs and charts to control visual elements alongside the music, creating a presentation that reacts directly to the chart.

The included EMS Creator allows creators to build and customize their own effect configurations.

Chart Editor

Create your own playable charts directly within Harmonic Drive.

The chart system supports:

* 4KEY–8KEY layouts
* Multiple difficulties
* Custom audio
* Community-created charts
* EMS integration
* Chart importing and sharing

Steam Workshop

Multiplayer

Harmonic Drive includes online multiplayer and cross-platform multiplayer functionality.

🛠️ Building From Source

Harmonic Drive is built using the Godot Engine.

Requirements

You will need:

* Git
* Godot 4.6
* A supported desktop operating system
* The dependencies required by the project

Clone the repository:

git clone git@github.com:KareelHicks/HarmonicDriveSteam.git
cd HarmonicDriveSteam

Then open the project in the appropriate version of Godot.

Note: Some proprietary, licensed, platform-specific, or redistributable-at-runtime components may not be included in the source repository.

🤝 Contributing

Contributions are welcome.

Harmonic Drive is being opened specifically because I want other developers and players to have the opportunity to improve the game.

If something bothers you, fix it.

If you have an idea for a game mode, prototype it.

If you think part of the UI could be better, improve it.

If you’re a rhythm-game expert and think a gameplay system could feel better, I especially want to hear from you.

A typical contribution workflow is:

1. Fork the repository.
2. Create a branch for your change.
3. Make and test your changes.
4. Commit your work.
5. Push your branch.
6. Open a Pull Request.
7. Explain what you changed and why.

Example:

git checkout -b feature/my-awesome-feature

Then:

git add .
git commit -m "feat: add my awesome feature"
git push origin feature/my-awesome-feature

Open a Pull Request against the main Harmonic Drive repository.

Please keep Pull Requests focused when possible. Smaller, well-tested changes are generally easier to review and merge.
